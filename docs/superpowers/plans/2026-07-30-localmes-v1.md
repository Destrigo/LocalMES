# LocalMES v1 Implementation Plan

> **For agentic workers:** Execute task-by-task. Steps use checkbox syntax.

**Goal:** Create a clean LocalMES open-source codebase (local-first MES, no ERP, English code, en/it UI, full `/api/v1` coverage) by selective port from `tmp_mes`.

**Architecture:** FastAPI + SQLite + React SPA; production serves SPA from API; session cookies for UI; API keys for integrations.

**Tech Stack:** Python 3.10+, FastAPI, SQLAlchemy, React 19, Vite, Tailwind 4, react-i18next

## Global Constraints

- No Danea / Newcos / hardcoded paths / real business data
- Code, DB columns, API paths in English
- UI strings via i18n (`en` + `it`)
- API under `/api/v1/...` with full field schemas
- Never add `Co-authored-by` to commits
- MIT license (already in repo)
